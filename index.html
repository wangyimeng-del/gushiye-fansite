表层 · 冰山

冷峻内敛、情绪极其稳定、不苟言笑，给人冷若冰山的距离感。

对你 · 冰川消融

会露出"像素点般的微笑"，暗含醋意，行动上极其可靠——是"冰川消融"式的温柔。

能力面 · 掌控天命

聪明绝顶、商业头脑极强、行事果断，有掌控天命的自信；但在"你"面前会失控、会破功。兼具双重人格特质，在不同副本中呈现霸总／军阀／仙君／帝王等侧面。

人设解析。顾时夜是"无限流"设定下最具掌控者气质的男主。他的核心矛盾是：一个算尽天命、俯瞰众生的人，偏偏算不出"你"的命，也偏偏为你破了功。各副本中身份虽变（总裁／军阀／仙君／帝王／星际统帅），但"他始终是他，唯一的他"——对"你"的偏爱与守护贯穿所有世界。

主线副本

WORLDS

人偶之匣

开服共通线悬疑密室

游戏开局的悬疑密室世界。玩家"你"在诡异人偶剧场中苏醒，在不同结局分支中认识四位男主；顾时夜以神秘掌权者／关键解谜者身份登场，是玩家遇到的第一位男主。

  • 初遇顾时夜；选择是否信任他
  • 解锁顾时夜个人分支结局
  • 成功／失败结局差异明显（患难之交、在一起、千年等待等）
「在看到她的那一刻，即使是在深渊之中，我也想不顾一切地来到她身边。」

迷失空间

主线现代悬疑

无尽密室类世界。玩家在循环空间中反复经历同一天，收集线索、思考关键词以打破轮回。

  • 收集房间线索，触发"危险的天台"
  • 电梯楼层选择导向不同结局（共赴未来／美好幻想／永困轮回）
「你总是不死心。」

无尽密室 · 深渊大厦

现代霸总无限循环写字楼

现代都市。玩家成为银非集团底层员工，被困在"深渊大厦"无限循环写字楼；顾时夜是银非集团总裁、大厦掌控者，持有高权限门禁卡。

  • 加班被困 → 逐层解谜 → 天台对峙
  • 联想链：深渊之眼＋安静的公司＝顾时夜身份；身份＋高权限门禁卡＝危险的天台
  • 电梯输入147层＝成功结局"留在人间"；180层＝失败结局"共赴深渊"
  • 彩蛋：银非集团＝Infinity，侧看像沙漏、等同于莫比乌斯环，暗喻无限循环
「没什么。想要你罢了。」

时代旧影

民国军阀先婚后爱

架空民国。北大州洛宁势力，顾家掌管冰海舰队与洛川陆军。玩家以留学归来富家千金身份融入洛宁上流社交圈，在宴会中与顾时夜相遇。

  • 宴会初遇 → 家族联姻／先婚后爱
  • 冰海舰队与战场危机；"发现《冰海》"剧情节点
  • 名卡「尽余欢」即出自此线（T0思维卡）
「……等我回来，想去哪里会带你去。」

仙途飘渺 · 金合欢之谜

仙侠仙君

仙侠修真世界。玩家成为金合欢圣教新任教主，教徒献上炉鼎；其中一名男子仙姿冰骨，长老只当是失明散修，只有"你"知道他是算尽天命的无尽天主人。趁他失忆，"你"将他留在身边重修旧缘。

  • 教主选炉鼎 → 识破仙君身份 → 趁失忆相伴
  • 石窟冰中救女；无尽天诀别与隔着重生
  • 2025年5月开放支线
「天上地下，世间运数，没有我看不到的……但我看不见你的命。」

天命（大倾）

古代帝王权谋宫变

架空古代王朝。大皇子刺杀不断、后宫皇后想杀人灭口。顾时夜从顾帅一路登基为帝，"你"为皇后，最终"你"看似皇后实则已把皇帝架空。

  • 北阗边关平叛 → 大皇子刺杀 → 神兵天降 → 烬血宫变
  • 易遇在宫中暗中布局；名卡「月枕山河」出自此线
  • 2026年5–6月上线
「我不会死。即使真的死了，过千年万年，也依然可以涅槃重生。」

  • 种田开局 → 星际战斗
  • 第17节"罢了，我跟你走"；第18节大结局"你是我苏醒的意义"
  • 2026年3月12–26日

独开至夜明

特殊副本翅膀西装

"你独自前往外市出差，走下站台，踏入这座看似繁华的都市，高楼之下却潜藏危机。"月光下高楼之上，坐着带翅膀的神秘西装男。

  • 出差抵达外市 → 月下高楼相遇 → 翅膀造型名场面
  • 世界侧影「万古长夜」配套剧情；同池柏源「归途无名」、易遇「千山暮雪」、夏萧因「月上黄泉」

此间即无间

特殊副本地狱无间

"你醒了？这里是……地狱。"地狱／无间设定的特殊副本，顾时夜以四天王之一身份登场（对应卡「不觉日长」）。

  • 地狱场景中的掌权者侧面
  • 卡面「不觉日长」即对应此线

迷失国度

暗黑童话春节克系悬疑

玩家收到神秘邀请函，进入一个有去无回的诡异小镇，居民每到零点集体消失；需化身经典童话角色，剧本全部逆转。顾时夜是《白雪公主》中的白雪公主，"你"是继母（黑王后）。

  • 收到邀请函 → 零点消失的小镇 → 童话角色逆转
  • 同期：夏萧因《卖火柴的小女孩》、柏源《小红帽与大灰狼》、易遇《海的女儿》
  • 2026年2月春节版本

云岭祀梦

特殊副本山灵祭祀

"山灵不语，梦入幽墟。"银铃阵阵、梦影重重的山村设定。同期柏源侧影「河倾月落」、夏萧因「蝶梦中网」。2026年3月25日上线。

  • 山灵祭祀、梦影重重的山村世界观

夏夜诡叙诗

特殊副本悬疑诡叙

悬疑诡叙式的夏夜小镇，与"此间即无间"相关。大结局中王晨晨想取代"你"，被顾时夜"天神下凡"轻松化解。对应卡牌「影」。

  • 第一天收集资料、选择不开门（开门走"暗中囚"结局）
  • 第二天解谜；大结局顾时夜天神下凡救场
  • 同池夏萧因「声」、易遇「镜」、柏源「相」；2026年5月限时重启

天地赋色

联动副本四域奇幻

四男主分属四域的奇幻联动：辉光狮境（柏源）、永暮森林（易遇）、奥术穹庭（夏萧因）、霜泣冻土（顾时夜）。最后一天"绮乔节"四男主剧情分P。2025年8月27日–9月8日。
